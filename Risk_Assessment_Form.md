# Risk Assessment Form

This form is dedicated to identifying and sharing intra-departmental Risk/Issues related to projects.

> **Note:** The name, email, and photo associated with your Google account will be recorded when you upload files and submit this form. Any files that are uploaded will be shared outside of the organization they belong to.

## Fields

| Field | Required | Type / Notes |
|---|---|---|
| Email | * | Auto-filled from Google account (checkbox to record) |
| Project ID | | Short answer |
| Risk ID | | Short answer |
| Date of Raising Risk | * | Date (dd-mm-yyyy) |
| Project Name | * | Short answer — insert the project name for which you want to request Issue/Risk/Change |
| Project Zone / Area | * | Short answer |
| Risk Identifier Name | * | Short answer |
| Risk Identifier ID / Employee ID | * | Short answer |
| Risk Category | * | Dropdown (choose) |
| Description of Risk | * | Long answer — details of requested Issue/Risk/Change |
| Likelihood of the Risk Occurring | * | Dropdown (choose) |
| Impact if the Risk Occurs | * | Dropdown (choose) |
| Risk Responsible | * | Short answer |
| Risk Accountable | * | Short answer |
| Mitigation Plan / Solution Details | * | Long answer — suggestions for resolving Issue/Mitigating Risk/Change management (if any) |
| Current Status | * | Dropdown (choose) |
| Add Attachment | | File upload — 1 supported file, max 10 MB |
